# 사업비서 — Discord 기반 일정 관리 자동화 에이전트

> Discord에 메모처럼 흘려 둔 할 일과 일정을, 매일 아침 9시에 AI가 읽고 정리해
> 다시 알려주는 개인용 자동화 에이전트입니다.

## 왜 만들었나

평소 떠오르는 할 일이나 잊으면 안 되는 것들을 Discord 채널에 메모처럼 적어 두는데,
쌓이기만 하고 정작 챙기지 못하는 경우가 많았습니다.
"쌓아 둔 메모를 누가 매일 아침 정리해서 알려주면 좋겠다"는 생각에서 시작해,
그 역할을 AI 에이전트에게 맡겨 보았습니다.

---

## 어떻게 동작하나

1. **수집** — 하루 동안 Discord 채널에 적어 둔 텍스트를 하나로 모읍니다.
2. **이해** — GPT-4o가 그 텍스트를 읽고, 제가 적은 말의 **의도와 내용을 파악**합니다.
   (단순 키워드 추출이 아니라, 문맥에서 "해야 할 일"이 무엇인지 해석)
3. **정리·알림** — 해야 할 일을 추출하고 요약해, 매일 오전 9시에 알림으로 전달합니다.

```
[사용자가 채널에 남긴 메모]
  "내일 지원서 마감", "OO에 이메일 답장", "장 봐야 함 - 우유, 계란"
        │
        ▼
[GPT-4o가 의도 파악 → 할 일 추출·요약]
        │
        ▼
[오전 9시 알림]
  ✅ 오늘 할 일
   1. 지원서 마감 (오늘까지)
   2. OO에게 이메일 답장
   3. 장보기: 우유, 계란
```

---

## 기술 포인트

- **자연어 메모 → 구조화된 할 일**: 형식 없이 흘려 쓴 메모를 GPT-4o가 해석해 할 일 목록으로 구조화. 사용자가 정해진 형식을 지킬 필요가 없다.
- **상시 가동 스케줄링**: AWS EC2 프리티어에 배포하고 스케줄러로 매일 오전 9시에 자동 실행. 개인용이라 트래픽이 적어 무료 플랜으로 충분하도록 가볍게 설계.
- **실사용**: 만들고 끝낸 것이 아니라, 현재까지 제 일정 관리에 직접 쓰고 있는 도구.

## 배운 점

- LLM을 "답변 생성기"가 아니라 **일상 워크플로우에 끼워 넣는 실행 단위**로 써 본 경험
- 클라우드에 상시 실행되는 서비스를 배포·운영하며, 비용(무료 플랜 한도) 안에서 동작하도록 설계하는 감각
